📊 계산 공식

1. 기본 공식 (선형 제품)

1본 중량 = 단위중량(kg/m) × 길이(m) 총 중량 = 1본 중량 × 수량(본) 견적금액 = 총 중량 × 단가(원/kg)

2. JavaScript 계산 로직

// 부등변ㄱ형강 계산 (선형 제품) if (calculatorData.calculationType === 'linear') { // 단위중량 × 길이 = 1본 중량 const weightPerPiece = unitWeight * length; // 1본 중량 × 수량 = 총 중량 calculatedWeight = weightPerPiece * quantity; // 계산 과정 표시 calculationSteps = [ `단위중량: ${unitWeight} kg/m`, `1본 중량: ${unitWeight} × ${length}m = ${weightPerPiece.toFixed(2)} kg`, `본수: ${quantity}본`, `총 중량: ${weightPerPiece.toFixed(2)} × ${quantity}본 = ${calculatedWeight.toFixed(1)} kg` ]; }

💡 계산 예시

입력값:

  • 제품: 부등변ㄱ형강 50×30×3T
  • 길이: 6m
  • 수량: 5본

계산 과정:

Step 1: 단위중량 확인
단위중량 = 1.830 kg/m
Step 2: 1본 중량 계산
1본 중량 = 1.830 kg/m × 6m = 10.98 kg
Step 3: 총 중량 계산
총 중량 = 10.98 kg × 5본 = 54.9 kg
Step 4: 견적금액 계산
견적금액 = 54.9 kg × 1,000원/kg = 54,900원
📋 계산 결과 표시:
