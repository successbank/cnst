철근 계산기 UI 활성화 테스트

1. 재질 선택 기능

활성화됨
  • ✓ 재질 버튼 클릭 가능
  • ✓ 클릭 시 파란색으로 변경 (active 클래스)
  • ✓ hover 시 배경색 변경
  • ✓ 재질명과 추가단가 표시
  • ✓ 선택한 재질이 결과에 표시

2. 길이 선택 기능

활성화됨
  • ✓ 드롭다운 선택 가능
  • ✓ 길이별 톤당 본수 표시
  • ✓ 포커스 시 테두리 색상 변경
  • ✓ 선택 시 자동 계산 실행

3. 톤 입력 기능

활성화됨
  • ✓ 숫자 입력 가능
  • ✓ 소수점 입력 지원 (step="0.1")
  • ✓ 최소값 1톤 설정
  • ✓ 입력 시 0.5초 후 자동 계산
  • ✓ Enter 키로 즉시 계산

4. 계산 및 초기화 버튼

활성화됨
  • ✓ 계산하기 버튼 클릭 가능
  • ✓ 초기화 버튼으로 모든 값 리셋
  • ✓ hover 시 버튼 효과
  • ✓ 전환 애니메이션 적용

5. 자동 기능

활성화됨
  • ✓ 페이지 로드 시 첫 번째 재질 자동 선택
  • ✓ 값 변경 시 자동 계산
  • ✓ 실시간 결과 업데이트

6. 계산 결과 표시

활성화됨
  • ✓ 규격, 재질, 길이, 톤수 표시
  • ✓ 총 본수, 총 중량 계산 및 표시
  • ✓ 기준단가 + 재질 추가단가 = 적용단가
  • ✓ 총 금액 계산 및 표시
  • ✓ 천 단위 콤마 표시
