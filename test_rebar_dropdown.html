📊 사용 가능한 길이 옵션

철근 D10 제품의 경우 다음 길이를 선택할 수 있습니다:

  • 6.0m ~ 12.0m (0.1m 단위)
  • 총 61개 옵션
  • 각 길이별로 DB에 저장된 톤당 본수 자동 적용
🧪 테스트 방법
  1. 아래 iframe에서 철근 D10 제품 페이지 확인
  2. 길이 드롭다운에서 다른 값 선택
  3. 계산 결과에서 "톤당 본수"와 "총 본수" 확인
  4. 예: 10.0m 선택 시 → 톤당 180본
🌐 실제 페이지
📝 계산 예시

입력값:

  • 제품: 철근 D10
  • 길이: 10.0m (드롭다운 선택)
  • 수량: 2톤

출력값:

  • 단위중량: 0.56 kg/m
  • 1본 중량: 0.56 × 10m = 5.60 kg
  • 톤당 본수: 180본 (10.0m 기준)
  • 총 본수: 180본 × 2톤 = 360본
  • 총 중량: 5.60 × 2본 = 11.2 kg
  • 견적금액: 11.2kg × 1,000원/kg = 11,200원
